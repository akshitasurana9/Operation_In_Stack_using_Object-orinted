Stack Operations Using C++

This project is a simple Stack Implementation in C++ developed as part of my BCA practical learning. The program demonstrates the basic working of the Stack Data Structure using arrays and classes with menu-driven operations.

Features
Push element into stack
Pop element from stack
Peek/View stack elements
Overflow and Underflow handling
User-friendly menu driven interface
Concepts Used
Object Oriented Programming (OOP)
Class Inheritance
Arrays in C++
Functions and Conditional Statements
Stack Data Structure (LIFO Principle)

This project helped me understand the practical implementation of stack operations and improved my knowledge of data structures and C++ programming.
